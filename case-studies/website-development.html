Web · 2022 – 2023

Website Development & Maintenance

Building and maintaining company profile websites for a confidential client, including the hosting, domains, and server behind them.

Project Overview

As a freelance webmaster I looked after company profile landing pages for a client. The pages were built with WordPress, and sometimes with plain HTML. I also managed the hosting and domains, and configured a web server on a VPS for the company's self-hosted websites. The client's name is withheld for confidentiality.

Problem or Challenge

The websites needed to stay online and working. Typical problems were scripts that stopped running, changes that had to be undone, and the risk of DDoS attacks taking a site offline.

My Role

  • Built and updated company profile landing pages with WordPress and plain HTML.
  • Investigated and fixed scripts that stopped working.
  • Restored websites from backup when needed.
  • Managed hosting services, domains, and DNS records.
  • Set up DDoS protection using Cloudflare.
  • Configured a web server on a VPS for self-hosted websites.

Technical Approach

When a site had a problem, I first looked for the script or change that caused it and fixed it directly. If that was not practical, I restored the site from a backup. Websites were placed behind Cloudflare for DDoS protection, and self-hosted sites ran on a VPS web server that I configured.

Tools and Technologies

  • WordPress
  • HTML5
  • CSS3
  • JavaScript
  • PHP
  • Cloudflare
  • VPS
  • DNS
  • Hosting & Domains

Results or Operational Benefits

The client had one person responsible for the whole chain: the pages, the hosting, the domain, and the server. Problems could be fixed or rolled back from backup, and the sites had protection against DDoS attacks.

Lessons Learned

Restoring from backup was sometimes the fastest way back to a working site, which is why keeping backups current matters as much as fixing the original fault.
