Pengembangan & Pemeliharaan Website

Membangun dan memelihara website profil perusahaan untuk klien yang dirahasiakan, termasuk hosting, domain, dan server di belakangnya.

Gambaran Proyek

Sebagai webmaster freelance, saya mengurus landing page profil perusahaan milik seorang klien. Halaman-halamannya dibuat dengan WordPress, dan kadang dengan HTML biasa. Saya juga mengelola hosting dan domain, serta mengonfigurasi web server di VPS untuk website yang di-host sendiri oleh perusahaan. Nama klien dirahasiakan.

Masalah atau Tantangan

Website harus tetap online dan berfungsi. Masalah yang umum terjadi adalah script yang berhenti berjalan, perubahan yang harus dibatalkan, dan risiko serangan DDoS yang membuat situs offline.

Peran Saya

  • Membangun dan memperbarui landing page profil perusahaan dengan WordPress dan HTML biasa.
  • Menelusuri dan memperbaiki script yang berhenti bekerja.
  • Memulihkan website dari backup bila diperlukan.
  • Mengelola layanan hosting, domain, dan DNS record.
  • Memasang proteksi DDoS menggunakan Cloudflare.
  • Mengonfigurasi web server di VPS untuk website yang di-host sendiri.

Pendekatan Teknis

Saat sebuah situs bermasalah, saya lebih dulu mencari script atau perubahan yang menjadi penyebabnya dan memperbaikinya langsung. Jika itu tidak praktis, saya memulihkan situs dari backup. Website ditempatkan di belakang Cloudflare untuk proteksi DDoS, dan situs yang di-host sendiri berjalan di web server VPS yang saya konfigurasi.

Alat dan Teknologi

  • WordPress
  • HTML5
  • CSS3
  • JavaScript
  • PHP
  • Cloudflare
  • VPS
  • DNS
  • Hosting & Domain

Hasil atau Manfaat Operasional

Klien memiliki satu orang yang bertanggung jawab atas seluruh rantai: halaman, hosting, domain, dan server. Masalah dapat diperbaiki atau dikembalikan dari backup, dan situs-situsnya terlindungi dari serangan DDoS.

Pelajaran yang Didapat

Memulihkan dari backup kadang menjadi cara tercepat untuk mengembalikan situs yang berfungsi. Karena itu menjaga backup tetap terbaru sama pentingnya dengan memperbaiki kerusakan aslinya.
